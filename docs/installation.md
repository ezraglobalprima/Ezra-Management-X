# Installation

## Status

Installation instructions are intentionally kept generic until the project's final runtime, dependencies, and deployment method are documented.

## Before Installation

Prepare:

1. A Telegram bot created through BotFather.
2. The required runtime for the current release.
3. The project's source code.
4. Required environment variables/configuration.
5. A secure location for secrets.

## Security

Never publish:

- Bot tokens
- API credentials
- Passwords
- Private keys
- Database credentials
- Other secrets

Do not commit `.env` files containing real credentials.
