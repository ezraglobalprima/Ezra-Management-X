# Security Policy

## Reporting a Security Issue

If you discover a security issue in Ezra Management X, do not publicly post sensitive details, credentials, bot tokens, or exploit information.

Contact the project developer through the official contact:

- Telegram: **@xrejax**
- Phone: **+62 857-3647-0670**

## Protect Your Credentials

Never publish:

- Telegram bot tokens
- API keys
- Passwords
- Database credentials
- Private keys
- Session files
- `.env` files containing secrets

If a secret has accidentally been exposed, revoke/rotate it immediately through the relevant service.

## Supported Versions

Support status will be documented as releases become available.
