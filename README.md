## 📌 About

**Ezra Management X** is a management system project developed and maintained by **Rejax (MOHAMMAD FIKI FAKHREZA)** under **Ezra Global Prima**.

The project is designed around structured management, role-based access control, configuration, documentation, and an extensible architecture.
